# Control Óptimo para EDOs

Materia / curso: **Control Óptimo para EDOs**  
**Profesora:** Constanza Sánchez de la Vega  

Repositorio con el material de las clases y las entregas de la materia.

## Programa (contenidos mínimos)

- Repaso de existencia y unicidad de soluciones de ecuaciones diferenciales ordinarias.
- Motivación de un sistema de control, relación entre estado y control, conjunto de controles admisibles. Aplicaciones.
- Funcional de costo dependiente del control, distintos tipos de funcionales. Control óptimo. Aplicaciones.
- Existencia de control óptimo.
- Condiciones de primer orden para un control óptimo. Principio de Máximo de Pontryagin. Sistema adjunto.
- Distintos tipos de restricciones: restricciones en el control, restricciones en el estado para tiempo final, restricciones en el estado para todo tiempo, restricciones mixtas.
- Ejemplos y aplicaciones (problema de la pesca, modelo de Goddard, modelos biológicos de crecimiento de bacterias o células, modelos SIR).
